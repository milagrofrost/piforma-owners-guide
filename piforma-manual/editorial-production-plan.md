## Findings and planned changes

1. Chapter 1 stops at startup rather than teaching a complete first session. Add pointing/clicking, AtEase launch, application Quit, and return via View → Show Desktop. Use About This PiForma as a small, documented practice window. Explain that showing the desktop does not quit applications.
2. Chapter 3 describes software components more often than everyday tasks. Teach ordinary mouse and keyboard actions, active windows, folders, application Save/Save As/Open, and game interactions. Keep commands conditional on the program presenting them; no universal shortcut map or guessed installed file-manager launcher.
3. Existing startup diagnosis is useful and must survive. Add a short symptom appendix that cross-references it and supplies safe exterior checks for the other requested symptoms.
4. Move low-level desktop stack names, internal rail details, component/controller names, conversion circuitry and archived gesture maps into Appendix A. Keep user-visible controls, source selection, sound-path distinctions and charging-while-off behavior in the chapters.
5. Owner-confirmed six-second close-active behavior supersedes the archived close-all map. Other tap/hold timings, DOSBox-X Ctrl+Esc, controller connectors/bindings, pairing and network menus remain unverified and must not become directions.
6. Move every PHOTO NEEDED, VERIFY and MODEL TO CONFIRM block into an editorial tracking file with its original location and wording. Remove prose addressed to the editor. Keep user-facing limits where needed to prevent a misleading instruction; do not hide missing operating coverage.
7. Existing photographs and outlines identify real controls. Retain proportions, captions correcting the mouse jokes, and the stand's deliberately unseated-leg explanation. Remove empty photograph boxes rather than shrinking useful labeled artwork. Preserve chapter-opening space and recto starts.
8. Keep the Forbidden Latch, second-left-click, Eye Correction Laser and service-department jokes. Follow each ambiguous label with the real control name or purpose.
