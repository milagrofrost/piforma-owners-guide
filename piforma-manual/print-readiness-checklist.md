# Print-readiness checklist — layout-reviewed proof

The trim PDF is suitable for a printer's physical proof. It is not an assertion of content sign-off, a physical paper proof, or a printer-specific PDF/X conversion.

## Verified in the delivered PDF

- [x] Exact 432 × 522 pt pages: 6 × 7.25 inches.
- [x] TrimBox and BleedBox equal the page; no edge-to-edge elements require bleed.
- [x] Embedded fonts; searchable text, vector text/rules and source-resolution raster images retained.
- [x] No compiler warnings, text overlaps or content outside trim.
- [x] At least 36 pt nominal binding clearance for essential text; wide plates have at least 40 pt inside clearance. PDF measurements account for canvas viewports.
- [x] Cover first; blank cover reverse; chapters open on right-hand pages; intentional blank versos have no running furniture.
- [x] All manuscript source hashes unchanged and all 346 manuscript text units present in the rendered PDF.
- [x] All 15 placed images accounted for, including cover, packing overview and rear drawing. Aspect ratios preserved; only empty side-view canvas is masked.
- [x] All pages inspected in rendered contact sheets; representative spreads and 72 ppi actual-size rasters opened, with 144 ppi detail checks.
- [x] Main rules, instruction markers and bullets use the single `#f34836` accent definition.
- [x] No binding-hole graphics, decorative backgrounds, carrier-sheet imposition or unrequested crop marks.

## Printer / physical-proof checks still required

- [ ] Confirm the printer's actual coil/spiral punch depth against the nominal 0.5-inch safe area and paper stock. The printer's punch specification was not supplied.
- [ ] Print at Actual Size, not Fit; inspect the smallest raster labels, fine strokes, grayscale bag photos, body text and red on the intended paper.
- [ ] Agree cover stock, front/back cover handling and whether the final unprinted reverse is supplied automatically. The 51-page reading order ends on a recto; no back-cover design has been invented.
- [ ] Choose the printer's color profile if required. Supplied raster leaders retain their source red, while editable typography uses the warm red accent. No arbitrary CMYK conversion or false spot-color claim was made.
- [ ] Confirm any PDF/X, bleed, crop-mark or imposed-sheet requirements with the printer before creating that separate production variant.
- [ ] Complete the existing editorial/device release checks in `editorial-production-tracker.md`, including the rear Audio Out callout. A layout review does not resolve those facts.
