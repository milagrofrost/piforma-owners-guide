# Glossary

<!-- evidence: editorial-advice; repo-verified D-SOFTWARE D-HARDWARE -->
## Apple Desktop Bus (ADB)

The connection system used by the original vintage keyboard before its Bluetooth conversion.

## AtEase

The PiForma’s folder-like launcher for opening configured programs.

## Bluetooth LE

Bluetooth Low Energy, the wireless connection used by the converted keyboard.

## Chime selector

The rear dial that chooses a startup sound; some settings are silent.

## Clippy

The assistant at the lower-right corner of the desktop. Type a question in its Chat with Clippy window; check its suggestions against the actual setup.

## Composite video

The video signal accepted by the rear RCA input, used to show an external source on the PiForma screen. The jack carries video only, not audio.

## Control Strip

The small program-launching and window-focus strip supplied by ControlStrip Simulator.

## Desktop

The working screen with its background, launchers, menu bar, and application windows.

## Docs Viewer

Macintosh PiForma Docs Viewer, the program for reading the project’s hardware, software and maintenance documents, with an offline snapshot. It is separate from About This PiForma.

## EmulationStation

The game-list menu of RetroPie, opened from AtEase. It is a separate application from the games it starts.

## Emulator

A program that imitates another computer or games system so compatible software can run.

## Full-screen application

A program occupying the display, often covering the normal desktop menus.

## GPIO

General-purpose input/output pins on the Raspberry Pi, used for controls in this build. Appendix A uses BCM pin numbering.

## HDMI

The digital video connection that carries the Raspberry Pi’s picture to the PiForma screen. Select HDMI on the rear source selector to see the Pi.

## microSD

The small storage card containing the PiForma’s operating system and saved files.

## PiForma Panel

The program that supplies the menu bar across the top of the screen, including the Special menu with Shut Down and Sleep Display.

## Qi charging

Wireless charging using an aligned transmitter and receiver.

## Raspberry Pi

The small computer board inside the PiForma case.

## Raspberry Pi OS

The operating system documented beneath the PiForma’s Macintosh-inspired desktop.

## RetroPie

The games/emulation environment, opened through EmulationStation in this setup.

## Save state

An emulator’s snapshot of a game in progress. It is a different facility from the game’s own save.

## Screen saver

An animation that fills the screen. On the PiForma, the Flying Toasters are a screen saver you start yourself; nothing starts on its own when the computer is idle. Hold the Apple logo for about six seconds to stop it.

## USB hub

An accessory that provides several USB connections from one computer port.

## Wi-Fi

The wireless network connection, managed by the operating system’s network tools. Bluetooth and the mouse receiver do not provide it.

There is no repair turnaround time and no promise that anything that breaks will ever be fixed. Repairs, if any, happen when the builder has a free weekend and the right part. Opening the Forbidden Latch voids this warranty, which costs you nothing, because there was never much of one to void.

# Radio and television interference

<!-- evidence: repo-verified D-HARDWARE; editorial-advice -->
The PiForma contains Wi-Fi and Bluetooth radios, a wireless charging receiver and a Raspberry Pi, all of which give off radio-frequency energy. Unlike the computers this guide imitates, the assembled PiForma has not been tested against the FCC limits for a Class B computing device.

If it interferes with radio or television reception, which you can find out by switching it off and on, move it farther from the receiver. Alternatively, switch off the television and play a tape through the PiForma’s rear composite input instead.
