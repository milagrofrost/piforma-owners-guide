# Glossary

<!-- evidence: editorial-advice; repo-verified D-SOFTWARE D-HARDWARE -->
## Apple Desktop Bus (ADB)

The connection system used by the original vintage keyboard before its Bluetooth conversion.

## AtEase

The PiForma’s folder-like launcher for opening configured programs.

## Bluetooth LE

Bluetooth Low Energy, the wireless connection used by the converted keyboard.

## Chime selector

The rear dial that chooses a startup sound; some settings are silent.

## Control Strip

The small program-launching and window-focus strip supplied by ControlStrip Simulator.

## Desktop

The working screen with its background, launchers, menu bar, and application windows.

## Emulator

A program that imitates another computer or games system so compatible software can run.

## Full-screen application

A program occupying the display, often covering the normal desktop menus.

## GPIO

General-purpose input/output pins on the Raspberry Pi, used for controls in this build. Appendix A uses BCM pin numbering.

## microSD

The small storage card containing the PiForma’s operating system and saved files.

## Qi charging

Wireless charging using an aligned transmitter and receiver.

## Raspberry Pi

The small computer board inside the PiForma case.

## Raspberry Pi OS

The operating system documented beneath the PiForma’s Macintosh-inspired desktop.

## RetroPie

The games/emulation environment, opened through EmulationStation in this setup.

## USB hub

An accessory that provides several USB connections from one computer port.
