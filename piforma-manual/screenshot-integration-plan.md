## Observed differences and limits

- Screenshot 1 visibly shows Apple, File, Edit, View, Special and a clock. A separate Time menu, Control Panel and individually identifiable Wi-Fi/volume controls are not established by this capture. Do not label invented controls. Control Panels is visible as an Apple-menu submenu in screenshot 3.
- Screenshot 3 is more than a menu selection: it also shows the About window. It supplies a useful information example without turning momentary memory figures into hardware specifications.
- The launcher label is PiForma Guide; the visible window title is Macintosh PiForma Guided Tour. Explain their relationship and retain the separate About app identity. The guide's lower line shows documentation status and a dated snapshot; do not claim it proves current online access.
- Screenshot 5 shows an existing conversation; subsequently supplied screenshot 11 confirms the message field and Enter/Send controls. Opening chat from the desktop remains unestablished, so no opening gesture is prescribed. Clippy's generic game-installation suggestions are not verified PiForma setup instructions.
- Screenshot 5's chat uses an upper-right close control. The themed document/About/file windows use a different layout. Do not make the upper-left close description universal.
- Screenshot 6 has terminal windows open; only its lower-left strip/popup is relevant. Do not present the terminal contents as operating instructions or a verified gesture map.
- Screenshot 8 shows the Save row highlighted in the application-local File menu while Apple, File, Edit, View and Special remain in the top system bar. It establishes the two separate menus, not a completed save. Do not infer whether a command succeeded from its highlight.

## Production

Keep numbered originals untouched. Store descriptively named lossless copies and a source/crop manifest. Use code-native SVG viewports to crop and, if the grayscale test remains clear, present the interiors in grayscale; never regenerate interface pixels or add fictitious controls. Captions/legends remain editable Typst text. Place captures with the relevant instructions, not in an end gallery. Review native UI lettering at print size, full-page renders, and facing-page previews after compilation.
